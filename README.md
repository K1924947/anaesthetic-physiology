# The Physio Lab

Interactive physiology teaching tools built by Dr Ed Kim. No installation required: open any page in a browser.

**Site:** [The Physio Lab](https://k1924947.github.io/anaesthetic-physiology)

---

## Tools

### Pressure–Volume Loop

An interactive cardiac PV loop exploring how the loop changes across physiological and pathological states.

- Morphing between states: Normal, increased/reduced preload, increased afterload, increased contractility, exercise, valve lesions, and ventricular failure
- Clickable phase segments: Filling, Isovolumetric Contraction, Ejection, Isovolumetric Relaxation
- Live readout: EDV, ESV, SV, EF, EDP
- EDPVR and ESPVR reference lines with a ghost normal loop for comparison
- Test yourself: guess how the loop changes, then reveal

---

### ECG Rhythm Quiz

An interactive lead II rhythm tool with synthetic strips, callipers, conduction diagrams, a Test yourself quiz, and guideline-based scenarios.

- Learn mode: pick a rhythm and read features, electrophysiology and a sourced management line
- Test yourself: identify the rhythm, then reveal
- Scenarios: scripted adult ALS situations based on the Resuscitation Council UK 2025 algorithms and the BNF
- Teaching simulation, not clinical guidance

---

### Cardiac Action Potential

An interactive action potential tool with a linked schematic ECG strip.

- Ventricular myocyte and SA node on the same axes, with Purkinje fibre and atrial myocyte as extras
- Clickable phases 0 to 4 with the main ion channels for each
- Scenarios: hyper/hypokalaemia (graded), hyper/hypocalcaemia, sympathetic and vagal tone, ischaemia, Vaughan Williams classes, adenosine and digoxin, each redrawn against a dashed normal
- Live readout: resting potential, threshold, phase 0 slope, APD90, SA phase 4 slope and rate
- Test yourself: predict, then reveal; revision summary, viva questions, key numbers and a Vaughan Williams table
- Every statement tagged Source, Physiology or Simulation; teaching simulation, not clinical guidance

---

### Cardiac Murmurs

An interactive murmur tool that links pressure gradients to the phonocardiogram.

- Left- and right-heart pressure traces with a hatched murmur envelope
- Normal and innocent sounds, systolic and diastolic valve lesions, and congenital lesions
- Bedside manoeuvres, a chest map, Test yourself questions, and a revision section
- Teaching simulation, not clinical guidance
